# live2d-xiaomai

内置小埋模型的live2d-widget

<img src="https://sina-vercel.wuuconix.link/large/007YVyKcly1hc9lbgfb67j30li0mpk0i.jpg" width="200px">

## 来源

项目代码来自 [[stevenjoezhang/live2d-widget](https://github.com/wuuconix/live2d-cdn)]

## 使用方法

在html文件中引入一个js文件即可。

```html
<script src="https://cdn.jsdelivr.net/gh/codeOvOcode/live2d-xiaomai@v0.1.0/autoload.js"></script>
```
